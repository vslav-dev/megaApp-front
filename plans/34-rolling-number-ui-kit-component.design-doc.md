# 34 — Rolling Number UI-Kit Component

## Что нужно

Переиспользуемый Angular-компонент в ui-kit, анимирующий смену текста числа посимвольно — каждый разряд едет/крутится к новому значению вместо мгновенной подмены строки. Технология взята из референса `/Users/user/code/rolling-digits.html` (посимвольное измерение через Range API, диф по разрядам с учётом позиции, пружинная физика через WAAPI).

Первое применение — значение метрики в заголовке карточки графика (`metric-chart-card`), при наведении на график и смене диапазона/гранулярности. Дефолтные параметры анимации, без экспонирования тюнинг-панели.

## Архитектура

Два слоя:

1. **Движок** (`rolling-number-engine.ts`, ui-kit-компонент-локальный, framework-agnostic класс) — вся логика: грэфемное разбиение текста, измерение позиции/ширины каждого глифа через скрытый текстовый узел + Range API, диф старого/нового текста (числовой парсер: префикс · целая часть · разделители тысяч · точка · дробная часть · суффикс, сопоставление от точки наружу; LCS как фолбэк для нечисловых кусков), физика пружины (аналитическое решение затухающего осциллятора, сэмплированное в keyframes WAAPI, с сохранением скорости при прерывании), жизненный цикл ячейки (mount/move/enter/exit).
2. **Angular-обёртка** (`v-rolling-number`) — держит host-элемент и скрытый текстовый узел, создаёт движок через `afterNextRender`, коммитит новый текст в движок через `effect()`, реагирующий на входной сигнал текста. Чистит анимации через `DestroyRef`.

Разделитель тысяч у движка определяется обобщённо (запятая или любой Unicode-символ категории Zs), чтобы работать с уже принятым в проекте `THIN_SPACE` без хардкода конкретного символа.

### Решение проблемы "прыгающей даты"

Вместо резервирования фиксированной ширины контейнера (прежний костыль на `metric-chart-card`, основанный на подсчёте макс. пиксельной ширины через `canvas.measureText` — `text-measure.ts`), используется приём из референса: перед мутацией текста измеряются `getBoundingClientRect()` соседних DOM-элементов (предыдущий/следующий sibling), после мутации — снова, и если сосед сдвинулся — сдвиг гасится пружинной анимацией `transform`, а не блокируется жёсткой шириной. Компонент сам ничего не резервирует — его бокс свободно меняет размер по контенту, а видимый прыжок соседей компенсируется анимацией. Это заменяет весь прежний хак (`headerValueReservedWidthPx$$`, `text-measure.ts`) — он удаляется.

### Что входит в v1

- Грэфемная сегментация (`Intl.Segmenter`, фолбэк на `Array.from`).
- Измерение глифов через скрытый текстовый узел + Range API.
- Двухслойный DOM (скрытый текст + оверлей с ячейками-спанами).
- Числовой диф с учётом разрядов + LCS-фолбэк для нечислового текста.
- Три режима дифа (посимвольная замена / LCS-морф / разряды-барабан), дефолт — барабан; переключение режима не выводится наружу в v1, но заложено в движке.
- Пружинная физика позиции ячейки + барабан-переворот цифры при смене значения разряда.
- Компенсация прыжка соседних DOM-элементов.
- Уважение `prefers-reduced-motion` (анимация полностью отключается, текст подставляется мгновенно).
- Корректная очистка анимаций при уничтожении компонента.

### Что не входит в v1 (сознательно отложено)

- Непрерывный "спин" барабана для живого тикающего значения (`startSpin`/`stopSpin` из референса) — не нужен для наведения на график, только для потокового фида цен.
- `IntersectionObserver` (пауза анимации для элементов вне вьюпорта).
- `ResizeObserver` для переизмерения при смене шрифта/зума — переизмерение и так происходит при каждом коммите нового значения.
- Idle-таймер разборки DOM-структуры обратно в один текстовый узел.
- Кап на количество графем, защита от патологически длинных строк.
- Кэш измерений по отпечатку шрифта (актуально для `tabular-nums`, в проекте не используется).

Эти пункты — расширение движка без изменения публичного API компонента, добавляются по запросу.
