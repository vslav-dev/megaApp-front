# Global Metrics Delta History — Implementation Plan (Frontend)

## Статус

- ✅ Завершено.

## Задача

- Убрать список сервисов и последний известный bucket из history-запроса.
- Отдельно находить первую нужную minute, hour и day свечу.
- Загружать непрерывный хвост от каждой найденной границы до актуальных данных.
- Сохранить один запрос, ручной полный refresh и защиту от повторного запроса реального общего простоя.

## Исходное состояние

- Сквозной minute-пробел используется только как boolean-сигнал.
- После сигнала повторно загружаются фиксированные окна всех известных frontend сервисов.
- Hour/day покрытие отдельно не проверяется.
- MegaBack получает список сервисов и сам вычисляет три нижние границы от последнего minute bucket.

## Решение

- Frontend хранит отдельный подтверждённый watermark и компактное bucket-покрытие для minute, hour и day.
- Для каждой гранулярности проверяется только диапазон после её watermark.
- Первая полностью пустая свеча становится inclusive lower bound этой гранулярности.
- Если проверенный диапазон старше retention-окна, lower bound ограничивается началом окна.
- Актуальная minute-граница берётся из realtime. Последние закрытые hour/day вычисляются из неё по UTC-границам периода.
- Если гранулярность уже актуальна, передаётся следующий ещё не закрытый bucket: Flatline возвращает для неё пустой набор.
- Первый запуск, legacy-кэш, ручной refresh и новый realtime-сервис используют полные retention-окна.
- Успешный ответ подтверждает только диапазон, существовавший на старте запроса. Новые live bucket проверяются следующим проходом.
- История продолжает сливаться по ключу гранулярности, сервиса, метрики и bucket.
- Локальные minute/hour/day данные ограничиваются своими окнами и не растут бесконечно.
- Кэш сохраняет отдельные watermarks. Старый числовой watermark применяется только к minute.

## Окна

- Minute: последние 24 часа.
- Hour: последние 30 дней.
- Day: последние 365 дней.
- Локальный 48-часовой minute-кэш сохраняется без изменения.

## Контракт

- Один запрос содержит `minuteSince`, `hourSince`, `daySince`.
- Каждая граница означает первый нужный bucket включительно.
- Список сервисов и имён метрик отсутствует.
- Ответ содержит историю всех сервисов, найденных Flatline в заданных диапазонах.
